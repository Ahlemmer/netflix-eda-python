# Netflix Content Strategy Analysis

## Overview
This project involves generating a synthetic, realistic dataset of Netflix shows and movies, followed by an Exploratory Data Analysis (EDA) to uncover trends in content additions, regional availability, and historical releases.

## Tools Used
* **Python** (Jupyter Notebook / Script)
* **Dataset: A synthetic Netflix-style dataset containing 5,000 records, used for practicing exploratory data analysis with Python and Pandas
* **Pandas & NumPy**: Data generation, manipulation, and cleaning.
* **Matplotlib & Seaborn**: Data visualization.

## Project Structure
* `netflix.ipynb`: The main script that cleans the dataset, and outputs visualizations.
* `netflix_data.csv`: The generated synthetic dataset (5,000 records).


## Key Insights
1. **Content by Country:** Visualizes the top 5 producing countries for Netflix content.
2. **Movie Releases (1990 - Present):** Highlights the distribution of movie releases over the last 30 years, showing a heavy skew toward recent releases.
3. **TV Shows vs. Movies:** A pie chart comparing the overall ratio of movies to TV shows on the platform.
4. **Optimal Launch Timing:** Analyzes the most popular months for adding TV shows to the platform.
5. **Recent Focus:** A stacked comparison showing how Netflix's strategy has shifted between TV Shows and Movies from 2015 onward.

## 🚀 How to Run
1. Clone this repository or download the Jupyter Notebook (`.ipynb`).
2. Open the notebook in **Jupyter Notebook** or **JupyterLab**.
3. Run the cells from top to bottom to execute the analysis.
